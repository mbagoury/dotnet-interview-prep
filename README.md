# Senior .NET & Architecture Technical Interview Platform

An interactive, high-performance web platform for preparing for, conducting, and scoring Senior .NET & Backend Technical Interviews.

## 🚀 Live Demo
- **Online Application:** https://mbagoury.github.io/dotnet-interview-prep/

## 📚 What's Included
1. **Interactive Interview Simulator**: Timed rounds, preset configurations (Senior General, Architecture, Performance), real-time scoring, observations, and automated scorecard report generation.
2. **Must-Ask Top 5**: Top priority questions curated across every chapter.
3. **Comprehensive Question Bank (353 Q&As)**: Searchable and filterable reference covering 20 chapters.
4. **25-Chapter Senior Revision Guide (75 Essential Q&As)**:
   - Architecture, C# Core, ASP.NET Core, Database Performance, EF Core, REST APIs, Security, Redis, RabbitMQ, Kafka, Microservices, Distributed Systems, Resilience, DDD, CQRS, Containers, Kubernetes, CI/CD, Observability, Azure Cloud, System Design, and Real-World Scenarios.
   - Includes **The 7-Step Senior-Level Answer Formula** & **Interactive Senior Interview Checklist**.
5. **SOLID Principles & Design Patterns Masterclass**: Side-by-side C# code comparisons, mapping matrix, and real-world multi-channel architecture.
6. **Active Recall Flashcards**: Spaced recall cards with keyboard flip navigation.
7. **Candidate Evaluation History**: Evaluation scorecards stored and exportable.

## 💻 Tech Stack
- Vanilla HTML5 / CSS3 / Modern JavaScript (ES6+)
- Client-Side Single Page Application (100% serverless, zero build-step)
- Responsive dark & light themes
